## 3. Core Loop

Игрок заходит → выбирает героя → попадает на арену → управляет джойстиком → герой автоатакует врагов → получает XP → характеристики растут автоматически → выживает → при смерти видит итоги уровня → получает кристаллы → тратит на апгрейды → возвращается в бой.

## 5. Бой

**Начальные характеристики:**

| Параметр | Значение |
|----------|----------|
| HP | 100 |
| Урон | 10 |
| Скорость атаки | 1.0 /сек |
| Радиус атаки | 2.0 клетки |
| Скорость движения | 3.0 клеток/сек |

**Формулы роста:**

| Параметр | Формула |
|----------|---------|
| DMG | `10 + (level - 1) * 3` |
| HP | `100 + (level - 1) * 6` |
| AS | `1.0 + floor((level - 1) / 5) * 0.1` |
| RNG | `2 + floor((level - 1) / 4) * 1` |

## 10. Монетизация

| Тип | Что даёт |
|-----|----------|
| Rewarded video | x2 награда после уровня |
| Interstitial | Между уровнями |
| IAP | Кристаллы, Pass |
| Battle Pass | Эксклюзивные награды |

**Потоки дохода:**
1. Реклама (rewarded + interstitial).
2. IAP (кристаллы).
3. Battle Pass.
4. Премиум-предметы.

---

## 11. Удержание

**Battle Pass:**
- Сезон = 30 дней.
- Уровни Pass = 30.
- Бесплатный трек + платный трек.
- Награды: кристаллы, скины, бустеры.

**Ежедневный календарь:**
- 7 дней.
- Награды: кристаллы, бустеры.

**Календарные события:**
- Тематические уровни.
- Уникальные награды.
- Отложено до после MVP.
